# SWUFE 讲座自动报名插件（浏览器扩展）

针对西南财经大学 WebVPN「学术讲座」系统的自动报名辅助工具。登录由你手动完成一次，插件在你设定的条件下接管后续的扫描与报名操作。

## 它能做什么

1. 在「查看学术讲座」列表页，由后台闹钟按你设置的间隔（默认 2 分钟）自动触发扫描（标签在后台/被冻结也会按时唤醒，无需保持页面在前台）
2. 自动点击「讲座报名」→ 弹出报名表格
3. 按你设置的条件过滤（校区/讲座形式/名称关键词/类别关键词/主办单位/课表冲突排除）
4. 命中且未报过的 → 自动点「报名」→ 严格判定结果（成功才推送，已满/失败自动冷却一段时间不再尝试）
5. 报名成功后记录到本地清单，并通过 Server酱 推送到微信
6. 每日固定时间（默认 23:00）汇总第二天要参加的讲座，推送到微信提醒

## 安装步骤（Chrome / Edge）

1. 解压本插件文件夹
2. 浏览器地址栏打开 `chrome://extensions`（Edge 用 `edge://extensions`）
3. 打开右上角「开发者模式」开关
4. 点「加载已解压的扩展程序」→ 选择 `swufe\_lecture\_plugin` 文件夹
5. 浏览器右上角出现本插件图标（可固定到工具栏）

## 使用流程

1. 正常登录 WebVPN，打开「学术讲座 → 查看学术讲座」页面（登录好、停留在该页）
2. 点插件图标 → 打开弹窗 → 填好条件；如需要微信通知，填写 Server酱 SendKey（可不填）→ 点「保存设置」
3. 勾选「启用自动扫描」→ 再点「保存设置」（保存后后台闹钟自动建立）
4. 插件由后台闹钟每 1\~2 分钟触发扫描/唤醒页面并报名（标签不用保持前台，但请保持 WebVPN 讲座页开着）
5. 报名成功后微信收到通知；次日讲座在设定时间提醒

## 条件说明

|条件|填写示例|含义|
|-|-|-|
|校区过滤|`柳林` 或 `光华`|只匹配地点含该校区（或对应教学楼）的讲座|
|讲座形式|`线下`|只匹配线下（可留空=不限）|
|名称关键词|`中国式现代化,资本市场`|讲座名称含任一即匹配|
|类别关键词|`《中国式现代化与经济高质量发展》讲座`|类别含任一即匹配|
|主办单位关键词|`金融学院`|主办单位含任一即匹配|
|课表冲突排除|在周课表网格里点格子|标记"这节有课"，讲座落在这节则不匹配|
|刷新间隔|`2`|分钟|

> 关键词用逗号分隔，多个之间是"或"关系（含任一即命中）。

### 校区与教学楼

插件按内置对照一并识别：

* 柳林：颐德楼、经世楼、格致楼、弘远楼、通博楼
* 光华：明德楼

## 课表冲突排除（避免与你的课撞车）

* 先选你的课表所在校区（柳林/光华），网格会按该校区显示"第 X 节 起止时间"
* 在周一\~周日 × 第 1\~N 节的网格里，点一下标为深蓝 = 这节你有课
* 扫描时插件会：① 从讲座日期算出是周几；② 把讲座时间与你标记的节次时段做重叠比较（按你的课表校区节次时间换算）→ 落在已标记节次则不匹配
* 两个校区节次时间不同：柳林 18:30 起第 10 节；光华下午 14:00 起、晚上 19:00 起，插件已内置对应表

## 讲座提醒

* 在「讲座提醒」卡片设置每日提醒时间（默认 23:00）
* 到点后后台自动汇总第二天要参加的讲座，通过微信发送提醒
* 提醒仅为文字通知，无法在微信里操作；如需取消报名，仍需登录系统手动办理

## 微信通知（Server酱 / 方糖）

### SendKey 怎么获取

方法一：浏览器

1. 打开 `https://sct.ftqq.com`，注册/登录 Server酱（方糖）账号
2. 进入「Key&API」页面，复制你自己的 SendKey

方法二：微信公众号

1. 搜索「Server酱（方糖）」
2. 在私信页面最下方中间点"视频教程"，选择"如何获取 SendKey"

### 下一步

1. 粘贴到插件弹窗的「Server酱 SendKey」输入框，点「保存设置」
2. 可点「测试推送」验证：微信能收到测试消息即配置成功
3. 注意免费额度每天 5 条

### 使用说明与限制

* **作用**：报名成功、次日讲座提醒等消息推送到你的微信；不填 SendKey 则不推送，其余功能正常
* **选填**：SendKey 只保存在本机浏览器（chrome.storage.local），不上传其他地方
* **限制**：通知只能发文字，无法在微信里操作；如需取消报名，请到学校系统办理；**免费额度每天 5 条，请留意推送数量**
* 若测试推送失败，请检查 SendKey 是否正确、网络能否访问 `sctapi.ftqq.com`

## 后台运行建议

* 插件由浏览器后台闹钟驱动，不需要保持页面在最前台；但标签页要保持打开（完全关闭页面就无法扫描）
* 建议把 WebVPN 标签页固定（钉住），并到 Edge 设置 → 系统与性能 →「睡眠标签页」→ 把 `webvpn.swufe.edu.cn` 加入从不休眠列表
* 会话失效（出现右上角失效提示）后，插件会自动刷新页面回到登录页；密码已填好则代为点击登录，通常直接回到讲座页；若仍停留在门户，再经应用中心进入「学术讲座」。若登录密码未填好，需要你手动登录一次

## 隐私与安全

* 账号密码不在插件里保存，登录仍由你自己在浏览器完成
* 报名条件、课表与已报名清单只存在本机浏览器存储中
