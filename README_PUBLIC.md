# SWUFE 讲座自动报名插件（浏览器插件）

针对西南财经大学 WebVPN「学术讲座」系统的自动报名工具。
登录需手机验证码、会话不保持 → 无法全自动脚本登录，改用**你手动登录一次 + 插件接管抢票**的方案。

## 它能做什么

1. 在「查看学术讲座」列表页，由**后台闹钟**按你设置的间隔（默认 2 分钟）自动触发扫描（标签在后台/被冻结也会按时唤醒，无需保持页面在前台）
2. 自动点击「讲座报名」→ 弹出报名表格
3. 按你设置的**条件**过滤（校区/讲座形式/名称关键词/类别关键词/主办单位/课表冲突排除）
4. 命中且没报过的 → 自动点「报名」→ 严格判定结果（成功才推送，已满/失败自动冷却）
5. 报名成功 → **Server酱推送到微信**（可选，不填 SendKey 则不推送）
6. **保险版**：报名后给你一个确认窗口，若未确认参加，将在讲座开始前 N 小时**自动取消报名**，避免"报了名没去 → 15 天禁报"的违约

## 安装步骤（Chrome / Edge）

1. 解压本插件文件夹
2. 浏览器地址栏打开 `chrome://extensions`（Edge 用 `edge://extensions`）
3. 打开右上角「开发者模式」开关
4. 点「加载已解压的扩展程序」→ 选择 `swufe_lecture_plugin` 文件夹
5. 浏览器右上角出现本插件图标（固定它）

## 使用流程

1. 正常登录 WebVPN，打开「学术讲座 → 查看学术讲座」页面（登录好、停留在该页）
2. 点插件图标 → 打开弹窗 → 填好条件（**Server酱 SendKey 可不填**，不填 = 不接收微信推送，其余功能正常）→ 点「保存设置」
3. 勾选「启用自动扫描」→ 再点「保存设置」（保存后后台闹钟自动建立）
4. 插件由后台闹钟每 1~2 分钟触发扫描/唤醒页面 + 抢报名（标签不用保持前台，但**请保持 WebVPN 讲座页开着**）
5. 抢到后微信收到推送 → 确认能否参加：
   - 能参加：什么都不用做（或到插件弹窗点「确认参加」）
   - 不能参加：到系统「讲座报名」取消，或插件弹窗点「取消报名」
6. 未在期限内确认 → 自动取消，防违约

## 条件说明

| 条件 | 填写示例 | 含义 |
|---|---|---|
| 校区过滤 | `柳林` 或 `光华` | 只抢地点含该字样的讲座 |
| 讲座形式 | `线下` | 只抢线下（可留空=不限） |
| 名称关键词 | `中国式现代化,资本市场` | 讲座名称含任一即抢 |
| 类别关键词 | `《中国式现代化与经济高质量发展》讲座` | 类别含任一即抢 |
| 主办单位关键词 | `金融学院` | 主办单位含任一即抢 |
| 课表冲突排除 | 在周课表网格里点格子 | 标记"这节有课"，讲座落在这节则不抢 |
| 刷新间隔 | `2` | 分钟 |

> 关键词用**逗号**分隔，多个之间是"或"关系（含任一即命中）。

## 后台运行建议（Chrome / Edge）

- 插件由浏览器后台闹钟驱动，**不需要**保持页面在最前台；但标签页要**保持打开**（完全关闭页面就无法抢）。
- 建议把 WebVPN 标签页**固定（钉住）**，并到 Edge 设置 → 系统与性能 →「睡眠标签页」→ 把 `webvpn.swufe.edu.cn` 加入**从不休眠**列表，双保险。
- 如果你把标签切到了别的页面，下一轮闹钟会自动把标签**导航回讲座列表页**继续抢。

## 课表冲突排除（避免与你的课撞车）

- 先选**你的课表所在校区**（柳林/光华），网格会按该校区显示"第X节 起止时间"
- 在**周一~周日 × 第1~N节**的网格里，点一下标为深蓝 = 这节你有课
- 抢课时插件会：① 从讲座日期算出是**周几**；② 把讲座时间与你标记的节次时段做**重叠比较**（用你的课表校区的节次时间换算）→ 落在已标记节次则**不抢**
- 两个校区节次时间不同：柳林 18:30 起第10节；光华下午 14:00 起、晚上 19:00 起，插件已内置对应表

## 保险版（防违约）逻辑

- 报名成功 → 记为「待确认」，开始计时
- 确认截止 = min( 报名后 `confirmWindowHours` 小时, 讲座开始前 `autoCancelHoursBeforeStart` 小时 )
- 到截止仍未确认 → 插件尝试自动点「取消报名」→ 微信推送结果
- 建议保持开启。确认窗口/提前取消小时数可在弹窗调整。

## 隐私与安全

- 账号密码**不在插件里保存**，登录仍由你自己在浏览器完成
- SendKey 只存本机浏览器（chrome.storage.local），且**可以不填**（不推送）
- 本项目仅供个人学习与校内讲座预约使用，请遵守学校管理规定
